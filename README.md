# Cunning Linguist

One-finger gesture remote for couples. Built for eyes-free use during oral sex (specifically cunnilingus guidance).

Open the page on a phone browser → go full-screen → she controls pressure, speed, and focus with simple swipes while her partner listens to the spoken cues.

## Gestures (default)

| Gesture | Cue |
|---------|-----|
| Swipe ↑ | Harder |
| Swipe ↓ | Softer |
| Two quick ↑ | Faster |
| Two quick ↓ | Slower |
| Circle (draw a loop) | Keep going / Circle that |
| Long-press | Right there / Don't move |
| Double-tap | Stop / Ease off |
| Swipe ← | Left side |
| Swipe → | Right side |

All phrases are editable in the settings panel (gear icon). Voice and speech rate are also adjustable. Settings persist in the browser.

## How to use

1. Open the hosted URL on the phone that will be the controller.
2. Tap the screen once to unlock speech (required by mobile browsers).
3. Hit the full-screen button (or add to home screen for an app-like experience).
4. Hand it over. Black screen, no looking required. Vibration confirms each recognized gesture.

Works offline after the first load. No accounts, no servers, no data leaves the device.
